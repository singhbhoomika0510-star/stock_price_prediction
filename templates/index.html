SYSTEM ARCHITECTURE

How does StockPredict AI work?

A clean, transparent machine learning pipeline built with Scikit-learn and Pandas.

01
Historical Data

Daily Open, High, Low, Close, and Volume ingested via Yahoo Finance.

02
Preprocessing

Chronological 80/20 train-test split without shuffling to avoid data leakage.

03
Feature Engineering

Price lags (Lag 1-3), 5/10/20-day SMAs, and intraday volatility %.

04
ML Model

Linear Regression computes optimal feature weights via Ordinary Least Squares.

05
Price Prediction

Multi-step autoregressive rollout predicts future trading days.
